## 🗂️ Core Knowledge Domains

- 📂 [[Developer Experience (devex) Frameworks - SPACE and Cognitive Friction|01. Developer Experience DX Frameworks and SPACE]] — Measuring Satisfaction, Performance, Activity, Communication, and Efficiency (SPACE); identifying developer bottlenecks, and optimizing local dev environments.
- 📂 [[Internal Developer Platforms (idp) - Spotify Backstage and Self Service|02. Internal Developer Platforms IDP and Portals]] — Building internal developer portals with Backstage, automated service scaffolding templates (cookiecutters), centralized service catalogs, and API discovery.
- 📂 [[SDK Engineering - Ergonomic Multi Language Client Library Architecture|03. SDK Design and Multi Language Client Libraries]] — Designing idiomatic, ergonomic client SDKs across Go, Python, TypeScript, and Java; automated generation from OpenAPI/Protobuf, error handling, and retries.
- 📂 [[Modern Developer Portals - Interactive Documentation (scalar, Stoplight)|04. Interactive API Documentation and Developer Portals]] — Building world-class developer documentation: Interactive code playgrounds, copy-paste curl recipes, error catalog resolution guides, and SDK onboarding guides.
- 📂 `05. Developer Advocacy, Content Creation, and Evangelism` — Writing engaging developer tutorials, building sample demo applications, producing technical videos and live streams, and translating complex tech into clear concepts.
- 📂 `06. Open Source Project Governance and Maintainership` — Managing GitHub open-source repositories: Contributor guidelines (`CONTRIBUTING.md`), code of conduct, issue triage automation, and community recognition.
- 📂 `07. Technical Evangelism and Conference Speaking` — Structuring compelling conference talk proposals (CFPs), designing visual slide decks, live coding presentation strategies, and storytelling for engineers.
- 📂 `08. Hackathons, Internal Tech Talks, and Guilds` — Establishing cross-team engineering guilds (Backend, Frontend, Security), hosting bi-weekly brown bag lunch & learns, and organizing internal hackathons.
- 📂 `09. Feedback Loops and Developer Sentiment Tracking` — Conducting quarterly developer satisfaction surveys, tracking Developer Net Promoter Score (DevNPS), analyzing friction logs, and driving platform roadmap fixes.
- 📂 [[Documentation Driven Development and API Usability Testing|10. Documentation Driven Development and API Usability]] — Writing API documentation and client sample code before implementing backend code, conducting usability tests on developer APIs, and validating ergonomics.
