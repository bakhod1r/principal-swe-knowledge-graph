## 🗂️ Core Knowledge Domains

- 📂 [[Blockchain Consensus Mechanisms: Proof of Work (pow) vs Proof of Stake (pos)|01. Blockchain Consensus Mechanisms Pow, Pos, and Tendermint]] — Nakamoto consensus, Byzantine Fault Tolerance (BFT), validator slashing, finality guarantees, and high-speed consensus (Tendermint/Raft).
- 📂 [[Ethereum Virtual Machine (evm) Architecture, Opcodes, and Gas Mechanics|02. Ethereum Virtual Machine EVM and Smart Contract Architecture]] — Stack-based EVM execution, storage vs memory vs calldata, gas metering, state tries (Merkle Patricia Trie), and smart contract compilation.
- 📂 [[Solidity Smart Contract Design Patterns and Proxy Upgradability (uups, Diamond)|03. Solidity Smart Contract Patterns and Upgradability]] — Writing gas-efficient Solidity code, Diamond multi-facet proxy pattern (ERC-2535), Universal Upgradeable Proxy Standard (UUPS), and storage layout collisions.
- 📂 [[Decentralized Storage: IPFS Content Addressing and Arweave Permanent Storage|04. Decentralized Storage Networks Ipfs, Arweave, and Filecoin]] — Content Identifiers (CID) based on cryptographic hashes, peer-to-peer pinning networks (IPFS), and permanent immutable storage architectures (Arweave).
- 📂 [[Token Standards and Digital Assets: Erc 20, Erc 721, and Erc 1155|05. Token Standards Erc 20, Erc 721, and Erc 1155]] — Fungible token standard (ERC-20), Non-Fungible token standard (ERC-721), Multi-token batch operations (ERC-1155), and metadata schemas.
- 📂 [[Zero Knowledge Proofs (zk Snarks, Zk Starks) and Privacy Engineering|06. Zero Knowledge Proofs Zk Snarks and Privacy Scaling]] — Prover-Verifier mechanics, arithmetic circuits, non-interactive zero-knowledge proofs, privacy-preserving transactions, and ZK-rollups.
- 📂 [[Layer 2 Blockchain Scaling: Optimistic Rollups vs Zero Knowledge Rollups|07. Layer 2 Scaling Rollups Optimistic vs Zk Rollups]] — Off-chain transaction execution, fraud proofs (Arbitrum, Optimism) vs validity proofs (zkSync, Starknet), sequencer centralization, and bridging.
- 📂 [[Smart Contract Security Auditing: Reentrancy, Front Running, and Flash Loans|08. Web3 Smart Contract Security Auditing and Reentrancy]] — Reentrancy attack mechanics and CEI (Checks-Effects-Interactions) pattern, flash loan vulnerability exploitation, oracle manipulation, and auditing tools (Slither, Foundry).
