## 🗂️ Topics

- 📂 [[Persistent Segment Tree|01. Persistent Segment Tree]] — Path-copying tree maintaining complete version history for range k-th smallest queries in O(log N).
- 📂 [[Link Cut Tree|02. Link Cut Tree]] — Dynamic forest maintaining paths via splay trees supporting link, cut, and path aggregates in amortized O(log N).
- 📂 [[Wavelet Tree|03. Wavelet Tree]] — Succinct data structure supporting range quantiles, rank, and select queries on large alphabets in O(log σ).
- 📂 [[Van Emde Boas Tree|04. Van Emde Boas Tree]] — Recursive universe-partitioning tree executing search, predecessor, and successor in O(log log U) time.
- 📂 [[Sqrt Tree|05. Sqrt Tree]] — Multi-level square-root decomposition tree answering static range queries in O(1) with O(N log log N) preprocessing.
- 📂 [[Patricia Trie Radix|06. Patricia Trie Radix]] — Practical Algorithm To Retrieve Information Coded In Alphanumeric: path-compressed radix trie.
- 📂 [[Hash Array Mapped Trie|07. Hash Array Mapped Trie]] — HAMT 32-way branching persistent map combining bitmap indexing with zero-rehash collision safety.
- 📂 [[Skip List|08. Skip List]] — Probabilistic multi-level express lane linked list delivering O(log N) expected search, insertion, and deletion.
- 📂 [[Rope|09. Rope]] — Binary tree string representation enabling O(log N) concatenation, insertion, deletion, and split for massive documents.
- 📂 [[LSM Tree|10. LSM Tree]] — Log-Structured Merge-tree cascading append-only MemTables and SSTables with background compaction.
- 📂 [[Merkle Tree|11. Merkle Tree]] — Cryptographic hash binary tree providing efficient, secure verification of distributed data integrity in O(log N).
