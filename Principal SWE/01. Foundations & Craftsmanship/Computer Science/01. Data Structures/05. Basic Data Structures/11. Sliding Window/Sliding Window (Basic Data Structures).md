## 🗂️ Operations & Topics

- [[Sliding Window Paradigm and Amortized O(1) Step Invariants]] — Maintaining continuous window state across contiguous subarrays in linear O(N) time.
- [[Fixed-Size Sliding Window (Running Aggregation)]] — Maintaining running sum across window of fixed size K by adding incoming and subtracting outgoing element.
- [[Variable-Size Dynamic Sliding Window (Expand-Contract)]] — Expanding right pointer to satisfy condition, contracting left pointer to optimize objective.
- [[Longest Substring Without Repeating Characters (Set Window)]] — Dynamic window with hash set tracking character frequency in O(N) time.
- [[Minimum Window Substring Algorithm (Character Match Counters)]] — Two-pointer window with required character frequency match counter in O(N).
- [[Subarray Product Less Than K (Counting Valid Windows)]] — Counting valid subarrays ending at right pointer via (right - left + 1) in O(N).
- [[Sliding Window Distinct Elements Count in Size K]] — Maintaining distinct element count in sliding window of size K using frequency map in O(N).
