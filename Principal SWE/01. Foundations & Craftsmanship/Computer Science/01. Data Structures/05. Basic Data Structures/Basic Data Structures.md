## 🗂️ Fundamental Data Structure Modules

- 📂 [[Array (Basic Data Structures)|01. Array]] — Contiguous memory buffers, pointer arithmetic, dynamic geometric resizing, and cache line striding.
- 📂 [[Linked Lists (Basic Data Structures)|02. Linked Lists]] — Singly, doubly, circular, unrolled, and intrusive heap/pointer linked lists with sentinel nodes.
- 📂 [[Queues (Basic Data Structures)|03. Queues]] — First-In First-Out (FIFO) ring buffers, lock-free SPSC Disruptor queues, and atomic CAS queues.
- 📂 [[Stacks (Basic Data Structures)|04. Stacks]] — Last-In First-Out (LIFO) call frames, monotonic Min/Max stacks, and parenthesis parsers.
- 📂 [[Hash Tables (Basic Data Structures)|05. Hash Tables]] — Linear probing, Robin Hood hashing, Cuckoo hashing, Swiss Tables SIMD control bytes, and consistent hash rings.
- 📂 [[Sets (Basic Data Structures)|06. Sets]] — Mathematical deduplication, 64-bit SIMD bitsets, hash sets, and ordered tree sets.
- 📂 [[Multiset Bag|07. Multiset Bag]] — Multiplicity collections, frequency counters, and dynamic tree multisets.
- 📂 [[Map Dictionary|08. Map Dictionary]] — Key-value associative stores, Robin Hood hash maps, RB-Tree ordered maps, and concurrent sharded maps.
- 📂 [[Deque (Basic Data Structures)|09. Deque]] — Double-ended queues, circular buffer blocks, and Chase-Lev work-stealing deque implementations.
