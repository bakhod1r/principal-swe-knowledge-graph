## 🗂️ Paradigms & Patterns

- 📂 [[Two Pointers|01. Two Pointers]] — Inward-converging, fast-slow, and boundary pointers eliminating nested search spaces from O(N^2) to O(N).
- 📂 [[Sliding Window|02. Sliding Window]] — Fixed and dynamic range aggregation maintaining continuous window invariants in amortized O(1) step time.
- 📂 [[Prefix Sums Difference Arrays|03. Prefix Sums Difference Arrays]] — Cumulative sum precomputations enabling O(1) interval queries and difference array batch range updates.
- 📂 [[Monotonic Stack|04. Monotonic Stack]] — Monotonically increasing/decreasing stacks solving next/previous greater/smaller elements and histogram areas in O(N).
- 📂 [[Monotonic Queue|05. Monotonic Queue]] — Double-ended deque maintaining candidate window extrema in amortized O(1) and accelerating DP transitions.
- 📂 [[Floyd Cycle Detection|06. Floyd Cycle Detection]] — Tortoise and Hare pointer algorithm detecting cycles, entry points, and cycle lengths in O(N) time and O(1) memory.
- 📂 [[Mex|07. Mex]] — Minimum Excluded Value algorithms, cyclic sort value-to-index mapping, and Sprague-Grundy game state transitions.
