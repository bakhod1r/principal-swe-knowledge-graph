## 🗂️ Core Knowledge Domains

- 📂 [[Clean Code Principles and Software Craftsmanship|01. Clean Code Principles]] — Meaningful naming, small single-responsibility functions, eliminating side effects, readable control flow, and automated refactoring.
- 📂 [[Programming Paradigms in Software Architecture|02. Programming Paradigms in Architecture]] — Procedural, Object-Oriented, Functional (immutability, pure functions), and Reactive programming in large-scale systems.
- 📂 [[Object Oriented Design and Composition Over Inheritance|03. OOP Foundations and Composition]] — Encapsulation, Polymorphism, Abstract Data Types, Liskov Substitution, and avoiding brittle inheritance hierarchies.
- 📂 [[Solid, Dry, Kiss, and YAGNI Design Principles|04. SOLID and Universal Design Principles]] — Single Responsibility (SRP), Open-Closed (OCP), Interface Segregation (ISP), Dependency Inversion (DIP), and Law of Demeter.
- 📂 [[GoF Design Patterns (creational, Structural, Behavioral)|05. GoF Design Patterns]] — Factory, Singleton, Builder, Adapter, Decorator, Facade, Composite, Strategy, Observer, Command, and Template Method.
- 📂 [[Core Architectural Principles and Modularity|06. Core Architectural Principles]] — High cohesion, low coupling, separation of concerns, stable abstractions principle, and stable dependencies principle.
- 📂 [[Architectural Styles (monolith, Modular Monolith, Soa, Microservices)|07. Architectural Styles]] — Structural topology trade-offs: Monoliths vs Distributed Services, service boundaries, and organizational fit.
- 📂 [[Layered, Hexagonal, Onion, and Clean Architecture Patterns|08. Architectural Patterns]] — Inversion of control at boundaries: Ports & Adapters, Domain Centric Core, Use Case interactors, and external adapters.
- 📂 [[Enterprise Integration Patterns (eip)|09. Enterprise Integration Patterns]] — Message Channel, Pipes & Filters, Message Router, Content-Based Router, Message Translator, and Saga orchestrators.
- 📂 [[Model Driven Software Design and Domain Modeling|10. Model Driven Software Design]] — Aligning executable code structures directly with underlying conceptual domain models and state machines.
