## 🗂️ Operations & Topics

- [[Two Pointers Paradigm and Search Space Reduction]] — Eliminating nested search loops by proving monotonic search space convergence.
- [[Opposite Direction Converging Two Pointers (Left and Right)]] — Inward-moving pointers converging from array boundaries (two-sum, palindrome).
- [[Same Direction Fast and Slow Two Pointers]] — Fast read head and slow write head for in-place compaction and cycle detection.
- [[Two Sum on Sorted Array (O(N) Optimal Scan)]] — O(N) search by moving left pointer right if sum < target, and right pointer left if sum > target.
- [[Three Sum Triplet Search (Sorting + Inward Two Pointers)]] — Sorting array + outer loop + converging two pointers solving 3-Sum in O(N^2) time and O(1) space.
- [[Container With Most Water (Greedy Wall Convergence)]] — Greedily moving the shorter boundary wall inward in O(N) time.
- [[Trapping Rain Water (Two Pointers Max-Height Traversal)]] — Tracking left_max and right_max boundaries in O(N) time and O(1) auxiliary space.
- [[Valid Palindrome Verification with Pointers]] — Comparing characters inward from both ends skipping non-alphanumeric runes in O(N).
- [[Two-Pointer In-Place Array Partitioning and QuickSort]] — Hoare partition converging pointers for optimal pivot positioning.
