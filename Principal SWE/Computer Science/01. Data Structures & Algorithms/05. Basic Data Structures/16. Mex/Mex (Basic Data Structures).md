## 🗂️ Operations & Topics

- [[Minimum Excluded Value (Mex) Definition and Axioms]] — Smallest non-negative integer not present in a given set or array.
- [[In-Place Cyclic Sort for Mex (A[i] == i Mapping)]] — Swapping positive integers to their matching index (A[i] == i) in O(N) time and O(1) space.
- [[First Missing Positive Algorithm (O(N) Time and O(1) Space)]] — Locating the smallest missing positive integer in an unsorted array in O(N) time and O(1) extra memory.
- [[Mex Query on Dynamic Array via Segment Tree]] — Segment tree tracking value frequencies to execute dynamic range Mex queries in O(log N).
- [[Mex in Sprague-Grundy Game Theory (Nim-Value Transitions)]] — Computing Grundy values for impartial combinatorial games via state transition Mex.
- [[Subarray Mex Computation and Frequency Counting]] — Computing Mex across sliding subarrays using frequency count tables.
