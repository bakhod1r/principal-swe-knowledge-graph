## 🏛️ Core Knowledge Domains

### 1. 📂 [[Data Structures & Algorithms|01. Data Structures & Algorithms]]
Asymptotic bounds, Master Theorem, amortized potential analysis, linear structures, Robin Hood/Cuckoo hashing, balanced trees, segment/Fenwick trees, heaps, graph flows, dynamic programming optimizations, matroid theory, and string automata.

### 2. 📂 [[Computer Architecture|02. Computer Architecture]]
CPU pipeline, instruction-level parallelism (ILP), superscalar execution, branch prediction, memory hierarchy (L1/L2/L3 caches, cache lines, MESI coherence), SIMD vectorization, and NUMA memory topologies.

### 3. 📂 [[Operating Systems|03. Operating Systems]]
Process scheduling, context switching overhead, virtual memory management (paging, TLB, page faults), system calls (syscall dispatch), inter-process communication (IPC), and kernel vs user-space boundaries.

### 4. 📂 [[Networking|04. Networking]]
OSI & TCP/IP models, TCP flow/congestion control (CUBIC, BBR), UDP transport, DNS resolution, TLS 1.3 cryptographic handshakes, HTTP/2 multiplexing, HTTP/3 QUIC, and socket programming.

### 5. 📂 [[Databases|05. Databases]]
Storage engines (B-Tree vs LSM-Tree, WAL), ACID transactions, isolation levels (MVCC, snapshot isolation, serializability), query planning/optimization, indexing strategies, and distributed consensus/replication.

### 6. 📂 [[Concurrency & Distributed|06. Concurrency & Distributed]]
Concurrency primitives (mutexes, atomics, CAS, memory barriers), memory models (JMM, Go memory model), actor model, CSP, CAP theorem, PACELC, distributed consensus (Raft, Paxos), and vector clocks.

### 7. 📂 [[Theory of Computation|07. Theory of Computation]]
Finite automata (DFA/NFA), regular expressions, context-free grammars, Turing machines, decidability, halting problem, complexity classes (P, NP, NP-Complete, NP-Hard), and reductions.
