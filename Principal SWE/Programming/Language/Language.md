## 🚀 Languages

### 🐹 1. [[Golang|Go (Golang)]]
- High performance, concurrency (GMP scheduler, channels), standard library, runtime internals, and cloud-native systems.

### ☕ 2. [[Java|Java]]
- Enterprise architecture, JVM internals, memory management (G1/ZGC), Spring ecosystem, and high-throughput backends.

### 🐍 3. [[Python|Python]]
- AI/ML ecosystems, data science, asynchronous programming (`asyncio`), language internals (CPython, GIL), and rapid services.

### 🦀 4. [[Rust|Rust]]
- Memory safety without garbage collection, borrow checker, zero-cost abstractions, systems programming, and async runtime (Tokio).

### 🗄️ 5. [[SQL|SQL]]
- Relational database management, query execution plans, indexing strategies, ACID transactions, and distributed data modeling.

### 🟦 6. [[TypeScript|TypeScript]]
- Static type system, advanced generics, compiler architecture, Node.js/Bun/Deno runtime, and large-scale web applications.

### 🐚 7. [[Shell-Bash|Shell / Bash]]
- Unix system administration, POSIX compliance, process control, automation pipelines, and infrastructure scripting.
