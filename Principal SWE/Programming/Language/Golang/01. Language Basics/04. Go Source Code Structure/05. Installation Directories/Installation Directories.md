# 📁 Go Installation Directories (`GOROOT`)

Ancillary directories installed within the `GOROOT` filesystem hierarchy.

---

## 🗂️ Directories

- [[bin]] — Public entry-point executables (`go`, `gofmt`).
- [[pkg]] — Compiled standard library archive files and metadata.
- [[doc]] — Official documentation, specifications, and articles.
- [[test]] — Test suites for compiler correctness, runtime benchmarks, and regression testing.
- [[misc]] — Miscellaneous tools, shell completions, and editor support files.
