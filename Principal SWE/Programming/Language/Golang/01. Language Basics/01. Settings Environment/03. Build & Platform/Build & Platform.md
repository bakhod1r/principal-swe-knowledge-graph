# 🏗️ Build & Platform Environment

Target operating system, architecture, and instruction set tuning variables for cross-compilation.

---

## 🗂️ Platform Variables

- [[GOOS]] — Target operating system (`linux`, `darwin`, `windows`, etc.).
- [[GOARCH]] — Target CPU architecture (`amd64`, `arm64`, `386`, `wasm`, etc.).
- [[GOAMD64]] — x86-64 microarchitecture levels (`v1`, `v2`, `v3`, `v4`).
- [[GOARM]] — 32-bit ARM instruction set version (`5`, `6`, `7`).
- [[GOARM64]] — ARM64 instruction set extensions.
- [[GOMIPS]] / [[GOMIPS64]] — MIPS architecture floating-point hardware support.
- [[GOPPC64]] — PowerPC 64-bit architecture code generation baseline.
- [[GOS390X]] — IBM System/390x instruction set features.
- [[GOWASM]] — WebAssembly execution mode and feature flags.
