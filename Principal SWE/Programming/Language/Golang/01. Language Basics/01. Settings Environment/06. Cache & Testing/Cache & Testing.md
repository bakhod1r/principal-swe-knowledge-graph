# 🚀 Cache & Testing Environment

Build artifact caching, test outputs, runtime debugging, and diagnostic facilities.

---

## 🗂️ Cache & Diagnostic Variables

- [[GOCACHE]] — Directory for compiled build artifacts and cached test results.
- [[GOTMPDIR]] — Directory for temporary files during build/test executions.
- [[GODEBUG]] — Controls Go runtime diagnostic parameters (`gctrace=1`, etc.).
- [[GOTRACEBACK]] — Controls detail level of panic stack traces.
- [[GOCOVERDIR]] — Directory for binary execution code coverage profiles.
