# 🧱 Core Concepts — Go Modules & Packages

Foundational building blocks of Go's dependency and packaging system.

---

## 🗂️ Topics & Components

- [[Module]] — Versioned collection of Go packages treated as a single unit.
- [[Package]] — Directory of `.go` source files sharing the same package declaration.
- [[go.mod]] — Primary module manifest declaring dependencies, versions, and replacements.
- [[go.sum]] — Cryptographic checksums (SHA-256) of direct and indirect dependencies.
- [[require]] — Directive specifying required dependency module paths and minimum versions.
- [[replace]] — Directive overriding dependency paths with local directories or custom forks.
- [[go.work]] — Multi-module workspace coordinator for simultaneous local development.
