# ⚙️ Build & Tooling Environment

Internal toolchain directories, default compiler flags, and experimental features.

---

## 🗂️ Tooling Variables

- [[GOFLAGS]] — Default flags automatically passed to the `go` command.
- [[GOTOOLDIR]] — Directory containing internal Go toolchain binaries (compile, link, asm).
- [[GOVERSION]] — Standard version string of the installed Go runtime.
- [[GOEXPERIMENT]] — Compiler experimental feature flags.
- [[GOFIPS140]] — FIPS 140 cryptographic compliance mode.
